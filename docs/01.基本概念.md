## 引言：强化学习的基本词汇

这里介绍强化学习一些最基本的概念，并通过网格世界（grid world）例子辅助理解。

> **本章路线图**：从单步交互的三要素（状态、动作、奖励）出发 → 串成跨时间的链条（轨迹、回报、回合）→ 最后用马尔可夫决策过程（MDP）把它们统一成一个数学框架。后续两章的状态值、贝尔曼方程都建立在这套词汇之上。

### 1、状态和动作

状态（state）：对环境在某一时刻的描述，反映智能体（agent）与环境的相对状况。在 grid world 中，状态就是智能体所在的具体网格，通过 $s_1,s_2,\dots$ 进行标识；所有状态的集合称为状态空间（state space）。Grid world 的状态是离散的，但一般的强化学习问题里，状态也可以是连续的，或者是高维向量。若状态满足马尔可夫性质（见第 6 节），则它包含了预测未来所需的全部信息。

动作（action）：描述的是智能体在每个状态下可采取的行为。每个动作都会带来一个结果，可能改变也可能不改变当前的状态。所有动作的集合称为动作空间（action space），表示为 $A=\{a_1,a_2,\dots,a_n\}$；表示某个具体状态的动作空间时，可用 $A(s_i)$ 表示。

> **记号与代码的对应**：本文沿用教材约定，状态和动作都从 1 开始编号：$s_1$ 是左上角的格子，按行优先依次编号；动作 $a_1,\dots,a_5$ 依次为向上、向右、向下、向左、原地不动。仓库代码 `src/rl_gridworld/env/grid_world.py` 中编号从 0 开始，状态为 `s = r * cols + c`，动作顺序为 `UP=0, DOWN=1, LEFT=2, RIGHT=3, STAY=4`。因此文中的 $s_i$ 对应代码中的状态 `i-1`，动作则要按名称对应，例如文中的 $a_2$（向右）是代码中的 `Action.RIGHT`（值为 3）。


### 2、状态转移

状态转移（state transition）：智能体从一个状态转移到另一个状态的**过程**。

状态转移的表示方式大致分为两种：表格（tabular）和条件概率（state transition probability）。

- 表格表示法：每一行对应一个状态，每一列对应一个动作，单元格里填写在该状态采取该动作后到达的下一状态。比较直观，但这种画法只方便描述确定性（deterministic）状态转移。
- 条件概率表示法：用条件概率来描述，且可以表示随机性（stochastic）的状态转移：

$$\begin{align}p(s_1|s_1,a_2)=0,\\p(s_2|s_1,a_2)=1,\\p(s_3|s_1,a_2)=0,\\p(s_4|s_1,a_2)=0,\\p(s_5|s_1,a_2)=0.\end{align}$$

上面的条件概率告诉我们，在 $s_1$ 状态下采取动作 $a_2$（向右）一定会使智能体转移到 $s_2$。


### 3、策略

策略（policy）：告诉智能体在**每一个状态**应该采取什么样的动作。也就是说，策略并不仅仅是某一单一状态的行为，而是包含了全部状态的全部行为。可以将其想象成一个二维结构：第一维是每个状态，第二维是当前状态下所有可能的**动作及其概率**。

在数学上，策略用条件概率描述（因而可以表示随机性 stochastic），通常用 $\pi(a|s)$ 表示在状态 $s$ 采取动作 $a$ 的概率。注意这里的 $\pi$ 不是圆周率，而是表示策略本身；$\pi(a|s)$ 的取值才是一个概率。

策略也可以用表格表示法（tabular representation）表示，便于理解。

> **确定性策略 vs 随机性策略**：当**所有状态**下都满足 $\pi(a|s)\in\{0,1\}$（每个状态恰有一个动作概率为 1、其余为 0）时，称为确定性策略（deterministic policy）；一般允许 $\pi(a|s)\in[0,1]$ 的称为随机性策略（stochastic policy）。确定性策略是随机性策略的特例。


### 4、奖励

奖励（reward）：$r$ 本质是一个实数，代表在某个状态执行某个动作后智能体得到的反馈，其值可以是正数、负数或零。

奖励是人机交互的重要方式：可以设置合适的奖励来引导智能体按照我们的预期来运动。

当前所描述的奖励是即时奖励（immediate reward），即采取一个动作后立刻获得的奖励。奖励同样可以用表格和条件概率两种方式表示。

奖励的数学写法由简到繁有三种：

- 确定性奖励 $r(s,a)$：在状态 $s$ 采取动作 $a$ 一定得到奖励 $r(s,a)$。本仓库的 grid world 就是这种情况。
- 奖励概率 $p(r|s,a)$：在状态 $s$ 采取动作 $a$ 得到奖励 $r$ 的概率，可以描述随机奖励。
- 联合分布 $p(s', r \mid s, a)$：标准 MDP 里最一般的写法。奖励可能和下一状态有关，分开写 $p(s'|s,a)$ 与 $p(r|s,a)$ 会丢掉“下一状态和奖励之间的相关性”。

如果只关心平均意义下的奖励，可以用期望奖励 $\bar r(s,a)=\mathbb{E}[R_{t+1}|S_t=s,A_t=a]=\sum_r r\,p(r|s,a)$ 来简化；奖励是确定的时，$\bar r(s,a)$ 就等于 $r(s,a)$。


### 5、轨迹、回报、回合

轨迹（trajectory）：一段由“状态-动作-奖励”交替组成的链条，写成 $S_0, A_0, R_1, S_1, A_1, R_2, S_2, \dots$。其中每一步 $S_t \xrightarrow{A_t} R_{t+1}, S_{t+1}$ 表示：在状态 $S_t$ 采取动作 $A_t$ 后，获得奖励 $R_{t+1}$ 并转移到 $S_{t+1}$。轨迹可以从任意状态截取一段，不要求从初始状态开始。

回报（return，$G_t$）：沿着一条轨迹、**从某个起点往后累加**得到的奖励之和（也是一个随机变量）。它绑定的是“起点 + 后续轨迹”，而不是“两个指定状态之间”的区间和。回报不是轨迹本身，而是从轨迹中提取出某个时刻之后的奖励序列，并对这些奖励进行累加得到的量。**它依赖于起点 $t$，记为 $G_t$。**

- 回报总是“从某状态出发往**后**算到轨迹末尾（或无穷）”。
- 正因为可以从轨迹上**任意一个状态**作为起点计算回报，才引出了后面的“状态值（state value）”——某状态的值，就是从它出发能拿到的回报的期望。
- 回报可在结构上拆为即时奖励（immediate reward）与未来奖励（future reward）：即时奖励是在起点执行动作后立刻获得的奖励；未来奖励是离开起点后续奖励（带折扣）的总和。
- 回报也称总奖励（total reward）或累积奖励（cumulative reward）。单条轨迹的回报评价的是这条轨迹的“好坏”；要评价一个策略，需要对回报取期望，也就是后面的状态值。

折扣回报（discounted return）：当轨迹无限长时，回报可能会**发散到无穷**。此时引入折扣因子（discount factor）$\gamma\in[0,1)$，对不同时刻的奖励添加相应折扣后再求和：

$$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \dots = \sum_{k=0}^{\infty}\gamma^k R_{t+k+1}$$

其中 $R_{t+1}$ 是即时奖励，其余各项之和 $\gamma(R_{t+2} + \gamma R_{t+3} + \dots) = \gamma G_{t+1}$ 是未来奖励，因此 $G_t = R_{t+1} + \gamma G_{t+1}$。这正是下一章推导贝尔曼方程的出发点。

由于 $\gamma\in[0,1)$，且在奖励有界（$|R_t|\le r_{\max}$）的前提下，折扣回报收敛于一个有限值（$|G_t|\le \dfrac{r_{\max}}{1-\gamma}$），不会发散到无穷。

折扣因子的用途：1. 允许考虑无限长的轨迹而不必担心回报发散；2. 调整对近期或远期奖励的重视程度（$\gamma$ 越小越看重近期）。

回合（episode）/ 尝试（trial）：执行一个策略与环境交互时，智能体从初始状态开始到终止状态（terminal state）停止的过程称为一个回合。

回合与轨迹概念相近：**回合是一条从起点到终点的有限长轨迹**（即 轨迹 ⊇ 回合）。如果任务的每个回合都会在有限步内到达终止状态（步数可以是随机的，不一定有固定上限），称为回合制任务（episodic task）；如果没有终止状态、交互永不停止，则称为持续性任务（continuing task）。

为了在数学上统一处理这两类任务，可以把回合制任务转换为持续性任务，转换方式有两种：

- 将终止状态视作一个特殊状态：专门设计其动作空间或状态转移，使智能体到达后永远停留在此，并**规定此后每一步的奖励都为 0**。这样的状态称为吸收状态（absorbing state）。由于之后的奖励全为 0，回报与原来的回合制任务相同，即使 $\gamma=1$ 也不会发散。
- 将终止状态视为普通状态：与其他状态一视同仁，智能体可能离开后再回来，停留在终止状态时也会持续获得奖励。此时回报可能无限累加，需要 $\gamma<1$ 才能保证收敛。本仓库的 grid world 采用的就是这种方式：目标格不是终止状态，在目标格原地不动会持续拿到目标奖励。


### 6、马尔可夫决策过程

马尔可夫决策过程（Markov decision process, MDP）是描述不确定环境下序贯决策问题的一般框架。它并不是强化学习独有的，但强化学习问题通常都建模在这个框架之上。一个 MDP 由以下要素组成，常记为五元组 $(S, A, p, r, \gamma)$，其中 $p$ 指状态转移概率，$r$ 指奖励：

- 集合：
	- 状态空间：所有状态的集合，记为 $S$。
	- 动作空间：与每个状态 $s\in S$ 关联的所有动作的集合，记为 $A(s)$。
	- 奖励集合：与 $(s,a)$ 关联的所有奖励的集合，记为 $R(s,a)$。
- 模型（model / dynamics）：
	- 状态转移概率：在状态 $s$ 采取动作 $a$ 时转移到状态 $s'$ 的概率 $p(s'|s,a)$，且对任意 $(s,a)$ 有 $\sum_{s'\in S}p(s'|s,a)=1$。
	- 奖励概率：在状态 $s$ 采取动作 $a$ 时获得奖励 $r$ 的概率 $p(r|s,a)$，且对任意 $(s,a)$ 有 $\sum_{r\in R(s,a)}p(r|s,a)=1$。
- 折扣因子：$\gamma\in[0,1)$（回合制任务也可取 $\gamma=1$），决定回报中远期奖励所占的权重。

策略不属于 MDP 本身，而是智能体在 MDP 上做出的选择：

- 策略：在状态 $s$ 采取动作 $a$ 的概率 $\pi(a|s)$，且对任意 $s\in S$ 有 $\sum_{a\in A(s)}\pi(a|s)=1$。同一个 MDP 可以搭配不同的策略，强化学习的目标就是在给定的 MDP 上找到最好的策略。

马尔可夫性质（Markov property）：随机过程的无记忆性，数学上表示为下一状态、下一奖励仅依赖当前状态和动作，而与更早的历史无关：

$$p(s_{t+1}\mid s_t,a_t,s_{t-1},a_{t-1},\dots,s_0,a_0)=p(s_{t+1}\mid s_t,a_t)$$
$$p(r_{t+1}\mid s_t,a_t,s_{t-1},a_{t-1},\dots,s_0,a_0)=p(r_{t+1}\mid s_t,a_t)$$
$$p(s_{t+1}, r_{t+1} \mid s_t,a_t,s_{t-1},a_{t-1},...)=p(s_{t+1}, r_{t+1} \mid s_t,a_t)$$

状态转移分布 $p(s'|s,a)$ 与奖励分布 $p(r|s,a)$ 共同描述了环境的模型（model）或动态（dynamics）。
更一般地，环境模型可用联合分布 $p(s',r|s,a)$ 表示：它描述智能体在状态 $s$ 采取动作 $a$ 后，转移到下一状态 $s'$ 并获得奖励 $r$ 的概率。在标准 MDP 中，该分布通常假设平稳；若随时间变化，则可写作 $p_t(s',r|s,a)$。


**从 MDP 到马尔可夫过程**：一旦策略**确定**（即概率分布 $\pi(a|s)$ 固定）下来，MDP 就退化为马尔可夫过程（Markov process, MP）；若仍保留奖励这一项，习惯上称为马尔可夫奖励过程（Markov Reward Process, MRP）。这里要特别注意——
> “策略固定”指的是**分布固定**，不是“每次执行的动作固定”。退化后的系统通常**仍然是随机的**，而不是确定性（deterministic）的。

MDP 中的随机性有三个来源：

1. 选哪个动作——由策略 $\pi(a|s)$ 决定；
2. 选了动作后转移到哪个状态——由 $p(s'|s,a)$ 决定；
3. 选了动作后得到多少奖励——由 $p(r|s,a)$ 决定。

策略固定后，智能体不再需要做决策，但这三个来源的随机性都可能还在：如果 $\pi(a|s)$ 本身是随机的，每一步仍要按它采样动作；状态转移和奖励是否随机，则取决于环境本身。固定策略后的状态转移概率为

$$p(s'|s)=\sum_a \pi(a\mid s)p(s'\mid s,a)$$

这仍是一个概率分布。只有当初始状态固定，且 $\pi(a|s)$、$p(s'|s,a)$、$p(r|s,a)$ **都退化成 0/1** 时，轨迹（包括其中的奖励）才唯一、可复现；否则从同一起点出发跑两次可能得到不同轨迹。所以准确表述是：**“不再需要做决策，但过程本身仍可能是随机的”**，而非“一切都确定了”。

下表假设初始状态固定、奖励是确定的：

| 策略 $\pi(a\|s)$ | 环境 $p(s'\|s,a)$ | 固定策略后的轨迹 |
|---|---|---|
| 确定性 (0/1) | 确定性 (0/1) | 唯一、可复现 |
| 确定性 | 随机 | 随机 |
| 随机 | 确定性 | 随机 |
| 随机 | 随机 | 随机 |

### 7、环境

强化学习的过程涉及智能体与环境的交互，智能体之外的一切都视为环境（environment）。智能体本身承担三重角色：

1. `感知者`：能够感知并理解当前的状态；
2. `决策者`：知道在什么状态应该采取什么行动；
3. `执行者`：能够执行策略所指示的动作，从而改变状态并得到奖励。
